# cr11-3: witness records grow without bound

**Intake verdict**: DECLINED

The file-count arithmetic is real, but the candidate provides no measured
failure or operational threshold. S4b deliberately requires immutable
hash-chained checkpoint files on cadence and periodic detection of historical
witness mutation; the proposed pruning, sealing, or suffix-only verification
would change those approved security semantics. Treat witness sizing and
cadence as an S7 operations-capacity topic unless concrete evidence justifies
a separately planned rotation design.
