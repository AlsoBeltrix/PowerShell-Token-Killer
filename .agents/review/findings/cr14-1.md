# cr14-1: pre-lineage v2 audit records brick published upgrades

**Severity**: CRITICAL — every published v0.2.x release wrote retained
`ptk.audit/2` records that current startup rejects before retention can remove
them.
**Status**: Verified
**Branch**: —
**Commit**: `9c0af0f7d5abbaf0e3ae62f0463d419edc113aef`

## Evidence

`v0.2.2:server/PtkMcpServer/Audit/AuditEvent.cs:180,823-833` labels the
serialized record `ptk.audit/2` and writes no
`producer.previous_supervisor_boot_id`. The v0.2.0 and v0.2.1 tags have the
same relevant shape. Current
`server/PtkMcpServer/Audit/AuditEvidenceSpoolScanner.cs:606-621` chooses the
producer property set solely from `schema_version` and requires the lineage
field on every v2 record; `RequireExactObject` rejects its absence at line 655.
`server/PtkMcpServer/Audit/AuditSpoolRecordCodec.cs:55-60` applies that same
validator to every retained spool record during journal startup.

The lineage field was added after v0.2.2 without a schema-version bump. Other
v2 consumers already treat it as optional:
`server/PtkMcpServer/Audit/Export/AuditExportService.cs:839` and
`siem/PtkSiemReceiver/Ingest/OtlpRequestValidator.cs:424-431`.

## Predicted observable failure

On an in-place upgrade from v0.2.0, v0.2.1, or v0.2.2, any retained closed
spool segment contains a v2 record without the lineage field. Journal startup
parses it before retention, throws `An evidence-proof audit object is
incomplete.`, and fail-closes every tool call. If awaiting evidence exists,
the reconciliation scanner fails on the same validator. Deleting the audit
root is the only existing recovery and destroys the retained record.

`previous_supervisor_boot_id` from a current v2 record and recomputes its exact

published producer-shape delta. The focused guard passes through both the

v2 compatibility arm makes
`Exact_envelope_shape_and_chain_codec_accept_pre_lineage_v2` fail with the
original `An evidence-proof audit object is incomplete.` startup exception;
restoring it passes. A separate v2 producer with an unknown extra member still
fails exact-shape validation. Focused scanner suite: 7/7 restored. The first

repo-recorded `StateToolTests` that inherit PTK's `PSModulePath`; those four
passed 4/4 after removing the inherited variable, and the full neutral-
