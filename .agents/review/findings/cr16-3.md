# cr16-3: zero signing identities bypass the intended diagnosis

**Severity**: LOW — macOS release failures with no imported signing identity
surface a misleading later `codesign` error instead of the workflow's explicit
identity guard.
**Status**: Repaired; final verification pending
**Branch**: —
**Commit**: pending final verification record

## Evidence

The signing step selected the second field from the first line of
`security find-identity -v -p codesigning`. With no identity, macOS prints
`0 valid identities found`; the command therefore assigned the literal word
`valid` to `IDENTITY`. The subsequent empty-string check did not fire and
`codesign --sign valid` failed later. The same position-only selection could
also choose an unrelated code-signing identity before the intended Developer
ID certificate.

## Predicted observable failure

An absent or failed certificate import reports that `valid` is not a usable
signing identity rather than the actionable workflow diagnostic. If another
identity is present first, the release can attempt to sign with the wrong
certificate and only fail at the authority assertion after doing work.

## Guard proof

`scripts/select-developer-id-identity.awk` selects by the quoted
`Developer ID Application:` identity type and emits only its 40-hex SHA-1
fingerprint. Its shell boundary independently validates that output before any
`codesign` call and emits an exact Developer ID diagnostic on failure.

`scripts/test-select-developer-id-identity.sh` covers zero identities, an
unrelated-only set, an unrelated identity before a valid Developer ID, a valid
Developer ID alone, a nonhex token, and a short fingerprint. The failure cases
assert the intended diagnostic as well as exit 1. Disabling only the boundary
fingerprint validation makes the zero-identity case fail at `expected exit 1,
got 0`. Broadening only the identity-type match makes the unrelated-only case
fail at the same assertion. Restoring both arms passes the selector suite.
Bash syntax, ShellCheck, `actionlint`, and `git diff --check` pass.
