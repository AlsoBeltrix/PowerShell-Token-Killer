## Predicted observable failure
An untrusted local process binds port 8317 first. PTK stands by; the
owner-only `ui-token` file exists (minted by this or an earlier boot). An
operator opening the UI sends the bearer token (header or query) to the
squatter, which can then release the port, wait for PTK to bind, and
replay the stolen token to read audit records or rewrite export settings.

## What
The trust model treats port ownership as proof of being a peer
supervisor, and the credential outlives any particular listener, so a
harvested token stays valid indefinitely. Verified at intake: token
minting precedes the bind, and the catch block is condition-free.
