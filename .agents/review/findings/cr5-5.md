## Evidence
`server/PtkMcpServer/Audit/Web/AuditWebUiService.cs:263` (LoadOrCreateToken) —
token creation is a check-then-act sequence, and line 280's
`File.Move(..., overwrite: true)` overwrites `ui-token` unconditionally
after each contender has generated its own in-memory token. Every
supervisor executes this before attempting the bind (line 106).

## Predicted observable failure
Two supervisors sharing a new audit root start concurrently; both
observe no token, generate different values, and overwrite the file
independently. The bind winner may serve token A while the file holds
token B; requests using the file's token receive 401.

## What
Token creation is not single-writer and is not tied to bind ownership,
so the value the listener authenticates against and the value the
operator reads can diverge.
