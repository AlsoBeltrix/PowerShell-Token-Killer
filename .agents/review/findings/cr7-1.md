## Evidence
`siem/PtkSiemReceiver/Web/OperatorEndpoints.cs:101` — with no Bearer
header, the full `token` query value authenticates; the dashboard reads
its token from the page URL (line 415).

## Predicted observable failure
`GET /api/chains?token=CANARY` puts CANARY into receiver logs.

## What
The query-parameter form existed to bootstrap the dashboard link; it
lets the credential travel in URLs, which are logged and remembered.

## Approach
Query-string auth is REMOVED: evidence endpoints are header-only. The
dashboard page itself is static HTML with zero evidence, so it serves
without auth (still Host-pinned); the operator pastes the token into
the page once, it is kept in sessionStorage, and every API call sends
it as a Bearer header. The URL never carries the credential.
