# or5-1: a failed reset/restart/close on one alias faults the whole host runtime

**Severity**: HIGH — one alias's failed lifecycle operation bricks every
healthy alias, including the warm default session, for the guardian's
lifetime with no in-band recovery.
**Status**: Verified
**Branch**: `feature/mcp-resilience-r1` (worktree `.claude/worktrees/mcp-resilience-r1`)
**Commit**: `74897a4`; reviewed range `ee58ed9..74897a4`; repair `94cea23`

## Evidence
`server/PtkMcpServer/GuardianHost/WorkerPrivateHostRuntime.cs` —
`ReplaceWorkerAsync`'s catch set `_state = Faulted`; `CloseWorkerAsync`'s
catch did the same. `_state` is host-global; `ValidateAndBind` and
`OpenWorkerAsync` then returned `SessionFaulted` for every alias forever.
The host protocol stays well-formed, so the guardian never replaces the
host.

## Predicted observable failure
Alias a's worker dies; the model issues `ptk_reset` (or session restart).
The replacement's shutdown/launch fails and the catch faults the runtime.
From then on every operation on every alias — including the healthy
`default` — returns session_faulted/SessionUnavailable, contradicting the
plan's "unexpected worker loss affects only its alias" and "one worker
circuit never restarts the host or another alias".

## What
Per-alias fault scoping: `AliasRuntime.Faulted`; the catch blocks mark
only the guilty alias (slot null, replacing cleared, faulted set, job
capabilities cleared) under the gate before writing a
`Ready/Resetting/Closing -> Faulted` lifecycle fact with
`CancellationToken.None` and an exact reason (`ContainmentUnconfirmed` for
a failed shutdown, `BootstrapFailed` for a failed relaunch).
`FrozenDefaultSessionState.ObserveSessionLifecycle` gained the `Faulted`
branch, which also clears the pending grant. The host-wide `Faulted`
transition remains for genuinely host-global failures.

## Files changed
`WorkerPrivateHostRuntime.cs` (fault scoping, helpers, checks),
`FrozenDefaultSessionState.cs` (Faulted branch),
`WorkerPrivateHostRuntimeTests.cs`, `FrozenDefaultSessionStateTests.cs`.
