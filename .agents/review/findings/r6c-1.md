## Predicted observable failure

- A host emitting its terminal ready lifecycle before `GuardianHostReady`
  must be admitted; any near-miss lifecycle (request id, worker identity,
  previous state, state, reason, readyForEffects, bootstrap state) must fault
  the client with a protocol violation. Covered by
  `GuardianHostClientTests.Initialize_accepts_exact_ready_session_lifecycle_before_host_ready`
  and `Initialize_rejects_nonexact_ready_session_lifecycle_before_ready`.
- The Unix init-drain stall returns: real apphost initialization hangs ~30s.
  Covered by `ProductionGuardianCompositionTests` real apphost tests.
- Shutdown write boundary lost: the WriteStarted delivery must precede the
  shutdown byte with the exact reserved request id. Covered by
  `WorkerClientTests.Client_exposes_the_reserved_request_id_before_the_shutdown_byte`.
- Replacement before old-generation shutdown. Covered by the order log in
  `WorkerPrivateHostRuntimeTests.Reset_shuts_down_old_generation_before_new_slot_becomes_ready`.
- Dynamic-binding acceptance/refusal drift. Covered by
  `WorkerPrivateHostRuntimeTests.Declared_cold_dynamic_alias_holds_no_slot_until_opened`
  and `Initialization_rejects_binding_shapes_the_runtime_does_not_accept`.

now routes all session work through contained workers; the guardian declared

sub-slice 4 work (ptk_session open, template bootstrap, single-use tokens)
cannot reopen single-alias assumptions.
