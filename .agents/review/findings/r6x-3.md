# r6x-3: `State_polling_is_guardian_local_and_scheduler_inert` is nondeterministic on Windows

**Severity**: MEDIUM — a mostly-failing test on Windows. It blocks a clean
Windows Guardian run (so it will block R6's acceptance matrix and any Windows CI
leg), but it is a test-determinism defect, not a proven product defect.
**Status**: Open — classified, cause not yet diagnosed
**Branch**: (none)
**Commit**: (none)

## Evidence

`PtkMcpGuardian.Tests.GuardianHostSupervisorTests.State_polling_is_guardian_local_and_scheduler_inert`
fails `Assert.Equal` expected `1`, actual `2` at
`GuardianHostSupervisorTests.cs:2267`, on `NETWATCH-01` (Windows NT
10.0.26200.0 x64, .NET SDK 10.0.302).

Isolated runs, 2026-07-25:

- head `168905c` (post-`r6x-1`-fix): **4 of 5 runs FAIL**
- head `31f550e` (pre-`r6x-1`-fix): **4 of 5 runs FAIL**

The identical failure rate at both heads is what establishes this is **not** a
regression from the `r6x-1` fix. It did not appear in the full-suite run at
`5e8b3be` simply because that single run got the ~1-in-5 pass.

## Predicted observable failure

Already observed. The assertion counts something expected to happen exactly
once and observes it twice, so the likely mechanism is an unsynchronised extra
poll or scheduler tick that Windows timing exposes far more often than
macOS/Linux — where the identity passes.

## What

The test asserts that state polling stays guardian-local and leaves the
scheduler inert. On Windows it usually observes two of whatever it counts
instead of one. Because it is ~80% failing rather than a rare flake, it is
tractable to diagnose directly rather than by long repetition.

## Approach

Not authored. Read the assertion's subject at
`GuardianHostSupervisorTests.cs:2267` and establish whether the second
observation is a genuine duplicate poll in the product or an unsynchronised
observation in the fixture. Do not "fix" it by loosening the assertion to accept
2 — that would discard whatever the guard exists to pin. If the extra
observation turns out to be real product behaviour, this becomes a product
finding rather than a test-determinism one.
